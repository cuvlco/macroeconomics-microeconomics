# ΚΕΦΑΛΑΙΟ 2ο
- P Τιμή
- QD Ζητούμενη ποσότητα
- Y Εισόδημα
- ED Ελαστικότητα Ζήτησης ως προς την τιμή
- EY Εισοδηματική Ελαστικότητα ζήτησης
- ΣΔ Συνολική Δαπάνη
- ΣΕ Συνολικά Έσοδα
- ΔQ Μεταβολή στη Ζητούμενη Ποσότητα
- ΔP Μεταβολή στη Τιμή
- ΔQ% Ποσοστιαία μεταβολή στη ζητούμενη ποσότητα
- ΔP% Ποσοστιαία μεταβολή στη τιμή




- Γραμμική Συνάρτηση : QD = α + β∙Ρ όπου β = ΔQ/ΔP
- α>0 (σταθερός όρος)
- β<0 (κλίση καμπύλης)

- Ισοσκελής Υπερβολή : QD = A/P όπου Α=ΣΔ=P∙QD

Ελαστικότητα Ζήτησης ως προς την τιμή ΕD

ED = (ποσοστιαία μεταβολή της ζητούμενης ποσότητας)/(ποσοστιαία μεταβολή τιμής)

ED σημείου = (ΔQ)/(ΔP) * (PΑ)/(QΑ)

ED τόξου = (ΔQ)/(ΔP) * (PΑ + PΤ)/(QΑ + QΤ)

ED ποσοστού = (ΔQ%)/(ΔP%)

- ΔQ% = (QΑ-QΤ)/(QΑ) * 100
- ΔP% = (PΑ-PΤ)/(PΑ) * 100

- ΔQ = QD(ΤΕΛΙΚΟ) - QD(ΑΡΧΙΚΟ)
- ΔP = P(ΤΕΛΙΚΟ) – P(ΑΡΧΙΚΟ)
# ΚΕΦΑΛΑΙΟ 3ο
- L (εργάτες/εργασία) Ποσότητα μεταβλητού συντελεστή παραγωγής
- Κ (κεφάλαιο) Ποσότητα σταθερού συντελεστή Παραγωγής
- Q ή ΤP : Συνολικό Προϊόν
- AP : Μέσο προϊόν / Προϊόν ανά εργάτη / παραγωγικότητα της εργασίας
- MP: Οριακό προϊόν / ρυθμός μεταβολής του συνολικού προϊόντος όταν μεταβάλλεται η
εργασία κατά μια μονάδα
- TC Συνολικό Κόστος (Total Cost)
- FC Σταθερό Κόστος (Fixed Cost)
- VC εταβλητό Κόστος (Variable Cost)
- ATC: Μέσο Συνολικό Κόστος (Average Total Cost) ή Μέσο κόστος ή Συνολικό κόστος ανά
μονάδα παραγωγής ή κόστος παραγωγής
- AFC Μέσο Σταθερό Κόστος (Average Fixed Cost) ή σταθερό κόστος ανά μονάδα
προϊόντος
- AVC Μέσο Μεταβλητό Κόστος (Average Variable Cost) ή μεταβλητό κόστος ανά μονάδα
προϊόντος
- MC Οριακό Κόστος (Marginal Cost)
- W αμοιβή / τιμή εργασίας
- C κόστος πρώτης ύλης ανά μονάδα προϊόντος
